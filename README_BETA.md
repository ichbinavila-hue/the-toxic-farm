# The Toxic Farm — Beta 0.2

Abra o projeto no Godot 4.x e execute `src/core/BetaMain.tscn` para testar a camada Beta isoladamente.

A cena Beta é uma sandbox de sistemas: progressão, clima, horário, missões, regiões e interações.

O projeto continua sendo uma base jogável de desenvolvimento. Não é uma build comercial final e não inclui arte, áudio, conteúdo e infraestrutura de produção completos.
