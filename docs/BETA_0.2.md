# THE TOXIC FARM — Beta 0.2

Esta build amplia o Alpha 0.1 com uma camada de progressão e estrutura para produção.

## Incluído
- ciclo de dia/horário;
- clima e bônus de agricultura;
- missões estruturadas;
- rotinas-base de NPCs;
- loja/catálogo;
- upgrades de ferramentas;
- chefe com fases e barra de vida;
- dados de regiões e requisitos;
- HUD beta;
- sprites SVG pixel-style para os cinco protagonistas e animais;
- cena BetaMain isolada para testar os sistemas sem depender do mapa antigo.

## Controles da cena Beta
- WASD/setas: mover
- Interact: registrar colheita
- Cast: descoberta espiritual
- F: avançar 30 minutos
- M: mineração
- 1: floresta
- 2: praia
- 3: minas
- 4: região espiritual

## Próximo passo de produção
Para uma versão comercial, ainda faltam assets artísticos finais, animações, áudio, UX completa, sincronização multiplayer autoritativa, save robusto/versionado, quests completas, conteúdo narrativo, balanceamento, testes, integração Steam e build/release pipeline.
