# Vertical Slice

Esta versão acrescenta:
- mapa visual da fazenda;
- personagem desenhado em runtime;
- inimigo de demonstração;
- seleção de personagem;
- seleção elemental;
- agricultura separada em sistema;
- progressão;
- inventário;
- combate base;
- multiplayer ENet para até 5;
- ciclo de dia;
- arquitetura preparada para expansão.

## Controles
WASD/setas = movimento
Espaço = magia
E = interação
Botão "Avançar dia" = teste de progressão da fazenda
