# Alpha 0.1 — Conteúdo implementado

## Jogabilidade
- seleção de personagem e elemento
- movimentação
- mapa de fazenda
- inimigo de demonstração
- combate-base
- inventário
- agricultura por sistema
- pesca
- mineração
- crafting
- animais
- progressão
- avanço de dia
- viagem entre regiões
- NPC base e diálogos
- save/load local

## Multiplayer
A sessão suporta até 5 jogadores no protótipo ENet. Para produção, todos os
sistemas de economia, inventário, combate e progressão devem migrar para
autoridade do servidor.

## Limitações conhecidas
- sprites são placeholders desenhados por código;
- não há assets finais;
- sincronização visual de movimento ainda é simplificada;
- não há matchmaking Steam;
- não há servidor dedicado;
- não há conteúdo completo de história;
- não há áudio final;
- não é uma build comercial de lançamento.

## Próxima etapa
Beta: servidor autoritativo, Steamworks/lobbies, sincronização de entidades,
agricultura visual, ferramentas, animais visuais, NPCs com rotina, quests,
bosses, save por jogador e conteúdo das cinco regiões.
